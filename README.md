#Version 1.00

【3Dプリンターで津軽三味線製作】Version 1.00 製作ガイド & README


本プロジェクトは、一般の方が3Dプリンターや比較的安価で入手可能な素材を用いて、  
自作で「津軽三味線」を製作するための手順を示したものです。  
伝統的な津軽三味線の構造をもとにデザインし、現代のデジタルファブリケーションとDIY技術で再現します。  
作者は本データを用いて皮を和紙、牛皮、山羊皮で貼って検証しました。それぞれ以下の特徴があります。

* 和紙：安価で加工が最も簡単。高音が綺麗に鳴る。
* 牛皮：高価で加工は大変だが、迫力の低音が響く。
* 山羊皮：本物に最も近い音色。費用と加工は中程度。

## 1. モデルデータ（3D CAD）
------------------------------------------------------------------------
配布しているモデルデータは、以下のフォルダに格納されています。

* **[/models/itomaki/] 糸巻き**
  * 一の糸巻き：正面から見て、天神の右上側の穴にさす糸巻き。
  * 二の糸巻き：正面から見て、天神の真ん中の穴にさす糸巻き。
  * 三の糸巻き：正面から見て、天神の左下側の穴にさす糸巻き。
  * ※念のため別のファイルになっていますが、構造が同じであるため、同じデータを三回作成しても問題ありません。

* **[/models/tenzin/] 天神・棹**
  * 天神：糸巻き、サワリ、上駒を組み合わせる三味線の構造の最上部。 
  * 上棹：天神、中棹の間に組み合わせる棹の一部。
  * 中棹：上棹、下棹＋前胴の間に組み合わせる棹の一部。
  * 下棹＋前胴：中棹、中木、右胴、左胴と組み合わせる棹と胴が組み合わさった部分。本物は別々になっている。
  
* **[/models/dou/] 中木・胴**
  * 中木：前胴と組み合わせる部分。先端の細い部分に音緒を付ける。 
  * 右胴：前胴と後ろ胴と組み合わせる胴の一部。
  * 左胴：前胴と後ろ胴と組み合わせる胴の一部。
  * 後ろ胴：右胴、左胴と組み合わせる胴の一部。

* **[/models/others/] その他**
  * 上駒：天神と組み合わせる部分。上側で弦の位置を整える。 
  * サワリ：天神と組み合わせる部分。三味線独特のバリバリとした音を出すのにとても重要。
  * 駒：胴に貼る皮の上に乗せる部分。
  * 撥：三味線を弾くのに使う道具。

### ※推奨3Dプリント設定:
* **素材**: 糸巻き、駒、サワリのみPETG, それ以外はPLA（ABSは非推奨）
* **インフィル**:
  * 糸巻き：100％
  * 天神・棹：50％
  * 中木・胴：50％
  * その他：100％
* **壁厚**: 4層以上（インフィル１００％の場合は設定不要）
* **充填パターン**: ジャイロ
* **サポート**: デフォルトのまま
* ※Bambu Studioバージョン2.7.6.12環境にて

## 3. 製作方法
------------------------------------------------------------------------
### 【STEP 1：パーツの印刷】
1. 順不同ではありますが上記のパーツを印刷していきます。  
   津軽三味線本体に関してのおすすめの順番としては  
   PLAで天神→上棹→中棹→下棹＋前胴→中木→右胴と左胴と後ろ胴を同時に→素材をPETGに変えて、糸巻き３本とその他を同時に印刷です。  
   ※天神、上棹、中棹、下棹＋前胴は平らな面を下向きに、右胴、左胴、後ろ胴は立てたまま印刷すると綺麗にできます。

2. サポート材を取り、サポート材がついていた面を整えます。

### 【STEP 2：皮の用意】
* 皮については研究時間が足らなく、最適解を見つけることが出来なかったので以下の中で気に入る特徴の物をお選びください。

  * **和紙**：加工のしやすさ、費用ともに一番最適です。固定の方法としては上からガムテープなどで胴と張り付けてください。ガムテープだと見栄え悪くなる場合もあるので、透明なOPPテープなどを使うのもおすすめです。和紙は胴より少し大きめ加工してください。音の面に関しては、低音は微妙なものの、高音部に関しては本物に近い音が鳴るためいい音が鳴ります。一方で本物にはある皮の張力は少ないため音の迫力は控えめであり、撥で叩いても鈍い音がします。

  * **牛皮**：加工は非常に大変であり、費用も最も高額です。加工法としては胴の大きさよりも40mmほど余裕をもって切り抜き、上部と下部には棹や中木が来ることを考慮し、そこを避けながら上下左右に穴をあけていきます。あけた穴に結束バンドを通していき、徐々に閉めていけばよい感じに牛皮が張れるはずです。音の面に関しては、和紙よりも迫力のある音になり、太鼓のような低音の良い響きがあります。

  * **山羊皮**：加工は牛皮ほどではないものの大変です。費用は和紙と、牛皮の間です。加工法は牛皮と同じ方法なのですが、強く引っ張るとすぐに破れてしまうためハトメをつけて破れないように対策するのをおすすめします。音の面に関しては、より音に迫力が出た和紙という感じの音です。本物に近い音が良い方はおそらくこれが一番おすすめです。

### 【STEP 3：組み立て】
1. 天神に糸巻きをいれていき止まったところで糸巻きに糸を通すための穴をドリルであけていきます。  
   * 一の糸巻きの位置は糸巻の太い側にドリルで2.0mmの大きさの穴をあける。
   * 二の糸巻きの位置は糸巻の太い側にドリルで1.5mmの大きさの穴をあける。
   * 三の糸巻きの位置は糸巻の細い側にドリルで1.0mmの大きさの穴をあける。  
   このような形で加工していただけると弦が穴にちょうどいいくらいの大きさに穴が開くと思います。

2. 天神→上棹→中棹→下棹＋前胴の順番に組み立てていきます。  
   * ※それぞれの接続部は向きが正しくないとはまらないので気を付けてください。
   * ※接続部の向きが正しい場合でもはまりづらい可能性があります。その場合はヤスリなどで整えてください。 

3. 2で作成したものの前胴の部分に中木を付け、その周りに右胴、左胴、後ろ胴を付けていきます。  
   * ※接続部の向きが正しい場合でもはまりづらい可能性があります。その場合はヤスリなどで整えてください。
   * ※中木や胴の部分は外れやすい場合があるので接着剤で固めるかはんだごてなどの熱で少し溶かし、接着することをお勧めします。

4. 上駒やサワリを天神の穴が開いた部分に付けます。  
   * ※上駒は非常に取れやすいため瞬間接着剤などで固定することをおすすめします。
   * ※サワリは可動式なため絶対に接着しないでください。

5. 「STEP 2：皮の用意」で準備したお好みの皮を張り付けてください。

6. 音緒を後ろ胴から出ている中木にとりつけ、弦を取り付けていきます。  
   * ※弦の張り方についてはこちらがおすすめです。  
     https://metal-shamisen.com/lesson11

7. 駒を皮と弦の間に挟んで、完成です。

## 4. 製作・運用における重要な注意点
------------------------------------------------------------------------
* **【製作物を加工する際の注意】**  
  3Dプリンターで作成したパーツをヤスリがけなどをして整える際に、摩擦熱が発生してしまうとパーツが変形してしまう恐れがあるため、耐水ペーパーなどを使用してください。

* **【サワリの調整】**  
  一の糸の特有の響き（サワリ）を再現するため、サワリを搭載していますが、本物とは違いねじ式ではなく、手動で位置を調節する仕組みであるため、あまり機能には期待しないでください。

* **【安全上の注意】**  
  ドリルや3Dプリンターフィラメントを溶かす際に発生する匂い、やすりなどで加工する際に飛ぶ粉末には十分注意し、作業時は十分換気をし、マスクや保護メガネを着用してください。
